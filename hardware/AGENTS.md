# AGENTS.md — hardware/

All PCB design work: Ergogen config, KiCad footprints, generated outputs,
Freerouting, and build scripts.

## Layout

```
hardware/
├── ergogen/
│   ├── config.yaml          ← main Ergogen config (EDIT THIS)
│   ├── old-config.yaml      reference only (previous iteration)
│   ├── sweep-like-minimal.yaml  reference only (ceoloide sweep-like example)
│   ├── footprints/
│   │   ├── ceoloide/        upstream ergogen-footprints (KiCad 8, git submodule)
│   │   └── imochoa/         local custom footprints
│   ├── 3dmodels/            STEP models for KiCad 3D viewer (choc, jst, switch, mcu)
│   ├── drc/                 AISLER manufacturer DRC rules (.kicad_dru)
│   ├── output/              generated by `just hardware ergogen-build`
│   │   ├── outlines/*.dxf
│   │   ├── cases/*.jscad
│   │   └── pcbs/shield-pcb.kicad_pcb
│   ├── manual/              hand-edited KiCad work (routing, gerbers)
│   └── schema.json          Ergogen config JSON schema (referenced by the $schema line)
├── package.json             pnpm project: ergogen:build, ergogen:watch scripts
├── .npmrc                   allows ergogen's exotic `hull` git subdep under pnpm 10
├── build.sh / rebuild.sh    podman-based ergogen + kicad8_auto + freerouting pipeline
├── bak.script.sh            backup of old build script
├── justfile                 ergogen + kicad recipes (run via `just hardware <recipe>`)
└── pcb*.pdf                 exported PCB PDFs (gitignored)
```

## Building / iterating

Recipes live in `hardware/justfile` and run from the repo root via
`just hardware <recipe>`:

```bash
just hardware setup            # pnpm install (one-time)
just hardware ergogen-build     # generate outlines/cases/PCB → ergogen/output/
just hardware ergogen-watch     # rebuild on config.yaml / footprint changes
just hardware visualize-dxf     # preview a generated outline (DXF)
just hardware kicad-checks      # DRC on the generated PCB
just hardware kicad-drc-aisler  # DRC with AISLER manufacturer rules
just hardware kicad-freerouting-gui  # autoroute via Freerouting
just hardware kicad-export-pdf  # front/back PDFs of the PCB
just hardware kicad-export-3d step  # 3D export (step/stl/glb/...)
just hardware ergogen-stl-from-jscad  # convert case .jscad → .stl
```

## Module justfile caveat

`just module` recipes run with `justfile_directory()` == the repo root (the
invoking justfile), NOT the module file's directory. So all paths in
`hardware/justfile` are prefixed with `hw := justfile_directory() / "hardware"`
and `ergogen := justfile_directory() / "hardware" / "ergogen"`. If you move
`hardware/justfile`, update these.

## Editing `config.yaml`

`config.yaml` is annotated with `# yaml-language-server: $schema=...` pointing
at the upstream Ergogen schema — keep that line intact.

Top-level sections: `meta`, `units`, `points`, `outlines`, `cases`, `pcbs`.

- **`units`**: Choc spacing (`kx=18mm`, `ky=17mm`), padding, MCU envelope, screw
  sizes. Prefer adding a unit over hard-coding mm.
- **`points`**: zones / columns / rows / key splay & stagger. Drives everything.
- **`pcbs.shield-pcb.footprints.mcu-fp`**: the `Pxx:` lines map MCU pins to
  ergogen key points. These drive the silkscreen labels AND the net connections
  on the PCB. They MUST match the kscan `input-gpios` in
  `firmware/config/boards/shields/ergogenesis/ergogenesis.dtsi`.

When changing keys/columns:
- Run `just hardware ergogen-build` and check `output/outlines/*.dxf` visually
  before touching PCB footprints.
- Net names (`col_net`, `row_net`) are wired in the `pcbs.*.footprints` section.

## Footprints

- **Upstream** (do not modify): `ergogen/footprints/ceoloide/*.js` — git submodule
  from https://github.com/ceoloide/ergogen-footprints. If something is missing,
  prefer adding the upstream file over rewriting it.
- **Local** (free to modify): `ergogen/footprints/imochoa/*.js`.
- Ergogen footprint API: https://docs.ergogen.xyz/footprint-format/

## 3D models

Component STEP models live in `ergogen/3dmodels/` and are referenced in
footprints via the `${ERGOGEN_3DMODELS}` KiCad path variable. To make KiCad's
3D viewer resolve them:

```
KiCad → Preferences → Configure Paths... → Add
  Name:  ERGOGEN_3DMODELS
  Value: <absolute path to>/ergogenesis/hardware/ergogen/3dmodels
```

## PCB / routing workflow

1. `just hardware ergogen-build` — generates the unrouted PCB.
2. Open `ergogen/output/pcbs/shield-pcb.kicad_pcb` in KiCad 8 `pcbnew`.
3. Save once so KiCad upgrades the file format.
4. `File > Export > Specctra DSN` → save next to the `.kicad_pcb`.
5. `just hardware kicad-freerouting-gui` — autoroutes (`-inc GND`, single thread).
6. In KiCad: `File > Import > Specctra Session` to pull routes back in.
7. `just hardware kicad-checks` — DRC.
8. `just hardware kicad-export-pdf` — front/back PDFs for visual check.

## Conventions

- Treat `ergogen/config.yaml` as the source of truth. Do not hand-edit generated
  files in `ergogen/output/` or the `.kicad_pcb` — regenerate instead.
- Keep YAML indentation at 2 spaces.
- The `ceoloide/` footprints are a git submodule — `git submodule update --init`
  if missing.
- `pnpm` is the package manager. `.npmrc` sets `block-exotic-subdeps=false` so
  ergogen's git-based `hull` dependency installs under pnpm 10+.
